# MeshCutoutByAlphas.py

[MeshCutoutByAlphas.py](./MeshCutoutByAlpha.py)

Blender 専用スクリプトです。透過テクスチャ画像を元に、自動でメッシュカットします。
アドオンではありません。`Script` ワークスペースのテキストエディターで開いて実行してください。

## このスクリプトで行うこと

元オブジェクトを複製し、UV（画像の貼り付け位置を指定する座標）をもとに、画像のアルファ値（透明度）を調べます。透明・不透明の境界付近を細分化し、透明と判定した面を削除します。

輪郭は細分化による近似なので、細い模様や小さな穴を正確に再現できない場合があります。

## 使い方

1. Blender を起動する
2. `Layout` ワークスペースを開く
3. 加工したいモデルを読み込む
4. `Outliner` （右上）で加工したいモデルを選択する
5. `Script` ワークスペースを開く
6. テキストエディターで `MeshCutoutByAlphas.py` を読み込む
7. `Text > Run Script` で実行する

## 基準画像を自動検出できないとき

ノード名が異なる場合や、候補が複数ある場合は、スクリプト冒頭の`IMAGE_BY_SLOT`で参照する画像を指定します。

たとえば、先頭のマテリアルスロットで使う画像のデータブロック名が`Image_15`なら、次のように設定します。

```python
IMAGE_BY_SLOT = {0: "Image_15"}
```

複数指定する場合は、次のようにカンマで区切ります。

```python
IMAGE_BY_SLOT = {
    0: "Image_15",
    1: "Image_18",
}
```

左側の数字は、対象オブジェクトのマテリアルスロットを上から数えた番号です。**先頭は0、次は1**です。右側は、画像テクスチャノードの画像選択欄で確認できる、Blender内の画像データブロック名です。ファイルの保存先パスやマテリアル名ではありません。

指定していないスロットでは、自動検出が使われます。使っていないスロットも含め、オブジェクトにあるすべてのマテリアルスロットが確認対象となる点に注意してください。

## パラメータ設定

スクリプト内で以下の値を変更できます。

```python
ALPHA_THRESHOLD = 0.05
SUBDIVISION_LEVELS = 4
DELETE_RATIO = 0.75
IMAGE_BY_SLOT = {}
```

| 設定 | 意味と調整の目安 |
| --- | --- |
| `ALPHA_THRESHOLD` | この値**未満**のアルファ値を透明と判定する。大きくすると、より不透明な部分まで透明扱いにななる。 |
| `SUBDIVISION_LEVELS` | 境界付近の細分化を繰り返す上限回数。増やすと輪郭の近似が細かくなる一方、面数と処理時間が増える。 |
| `DELETE_RATIO` | 透明・不透明が混在する面について、透明サンプルの割合がこの値**以上**なら削除する。`1.0`にすると混在面は残り、すべてのサンプルが透明の面だけが削除される。 |
| `IMAGE_BY_SLOT` | 自動検出を使わず、マテリアルスロットごとに参照画像を指定する。 |
